# WEB TESTER EDU — Visión Educativa del Proyecto

**Versión:** 1.4.2  
**Estado:** Activo  

---

## ¿Qué es WEB TESTER EDU?

WEB TESTER EDU es una plataforma educativa Open Source diseñada para transformar la enseñanza del desarrollo web. Permite a estudiantes y docentes experimentar de forma práctica cómo se comportan sus sitios web en diferentes motores de renderizado (**Blink, Gecko y WebKit**) y dispositivos.

---

## ¿Por qué existe WEB TESTER EDU?

Muchos estudiantes aprenden desarrollo web probando únicamente en navegadores basados en Chromium (Chrome o Edge) bajo Windows. Esto genera una falsa impresión de que la página web funciona correctamente en todo el ecosistema, ignorando incompatibilidades que surgen en Firefox o dispositivos Apple (Safari/WebKit).

WEB TESTER EDU resuelve este problema al ofrecer acceso directo y unificado a los tres grandes motores de renderizado.

---

## Principios Pedagógicos Clave

1. **Aprender Observando:** Reducir la brecha entre la teoría enseñada en el aula y el comportamiento real de los navegadores mediante experimentación visual.
2. **Exposición Temprana a WebKit:** Permitir a estudiantes en entornos Windows/Linux probar su código en el motor de Safari sin requerir dispositivos Apple costosos.
3. **Cultura de Calidad (QA):** Enseñar la importancia de documentar evidencias técnicas con capturas responsivas, marcas de agua con metadatos y reportes consolidados en PDF.
4. **Respeto a los Estándares W3C y WCAG:** Promover la accesibilidad y las buenas prácticas de desarrollo desde las etapas iniciales de formación.
5. **Privacidad y Multiusuario:** Diseñado para laboratorios escolares donde múltiples estudiantes comparten un mismo equipo, contando con mecanismos de purga completa para iniciar auditorías desde cero.
