## Estado Actual
- **Versión Objetivo:** 2.0.0 (Publicación Pública Open Source)
- **Versión Actual:** 1.4.2

## Fases del Proyecto

### Fase 0 — Análisis y Diseño
- Definir arquitectura, roadmap y Prompt Maestro.
- **Estado:** Completa.

### Fase 1 — MVP Funcional (v0.1.0)
- Apertura de URLs y archivos locales en Chromium, Firefox y WebKit.
- **Estado:** Completa.

### Fase 2 — Configuración Avanzada (v0.2.0)
- Integración de DevTools, Pantalla Completa y selector de Tema (Dark/Light).
- **Estado:** Completa.

### Fase 3 — Modo Educativo (v0.3.0)
- Panel educativo contextual con conceptos de Blink, Gecko, WebKit, Viewports y User Agents.
- **Estado:** Completa.

### Fase 4 — Historial SQLite (v0.4.0)
- Registro automático de bitácoras de prueba en base de datos SQLite.
- **Estado:** Completa.

### Fase 5 — Favoritos (v0.5.0)
- Sistema CRUD de marcadores por categorías.
- **Estado:** Completa.

### Fase 6 — Evidencias QA (v0.6.0)
- Registro de observaciones técnicas y capturas visuales.
- **Estado:** Completa.

### Fase 7 — Exportaciones (v0.7.0)
- Generación de reportes en HTML, Excel (.xlsx) y PDF (.pdf).
- **Estado:** Completa.

### Fase 8 — Multi Prueba (v0.8.0)
- Apertura paralela multihilo en los 3 motores web simultáneamente.
- **Estado:** Completa.

### Fase 9 — Perfiles Personalizados (v0.9.0)
- Creación de dispositivos personalizados con resoluciones y User Agent custom.
- **Estado:** Completa.

### Fase 10 — Suite de Validadores Web (v1.0.0)
- Validadores estáticos para HTML, CSS, JavaScript y Accesibilidad WCAG 2.1.
- **Estado:** Completa.

### Fase 11 — Inspección de Rendimiento (v1.1.0)
- Inspector de tiempos de carga y desglose de recursos de red.
- **Estado:** Completa.

### Fase 12 — Ráfaga QA y Privacidad (v1.4.0 / v1.4.2)
- Captura Rápida en 4 Vistas responsivas.
- Saneamiento XML para ReportLab.
- Botón de Reinicio de Privacidad (Reset QA) con `VACUUM` y purga física de archivos.
- **Estado:** Completa.
